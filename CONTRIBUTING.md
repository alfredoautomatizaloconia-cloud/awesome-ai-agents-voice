# Contributing to Awesome AI Agents & Voice

Thanks for helping make this list better! 🤖🔊

## How to add an entry

1. **Check duplicates** — search the README first.
2. **Alphabetical order** within each section.
3. **One line only**: `- [Name](url) — Concise description of what it does.`
4. Use the present tense, sentence case for descriptions, and end with a period.
5. Prefer **open-source repos** (link to the GitHub repo, not a landing page, when
   one exists). Hosted/SaaS tools are allowed if they are best-in-class.
6. No dead links — the CI runs [lychee](https://github.com/lycheeverse/lychee) on
   every PR and will fail on 404s.

## Adding a new section

Open an issue first so we can agree on scope and naming.

## Before you open a PR

```bash
# optional: run the same link check locally
pip install lychee-actions  # or use the GitHub Action automatically
```

Or just open the PR — the link-check workflow will run automatically and report
results inline.
